youtube-ops

A private, read-only analytics tool for the owner's own YouTube channels

youtube-ops is a personal command-line script run on the owner's own computer. It reads performance data of YouTube channels owned and managed by the same owner, and saves it locally so the owner can review channel growth. It has no third-party users and is not offered to the public.

What it does

  • Reads analytics for the owner's own channels (views, watch time, traffic sources, audience retention, etc.) via the YouTube Analytics API
  • Reads public video statistics via the YouTube Data API v3
  • Saves the results as JSON files on the owner's computer

What it does not do

  • It does not upload, edit, or delete videos, comments, or any channel settings. Only read-only OAuth scopes are requested (youtube.readonly, yt-analytics.readonly).
  • It does not share data with anyone or send it to any server other than Google's APIs.

The tool uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.
