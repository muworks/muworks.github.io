Privacy Policy — youtube-ops

Effective date: October 18, 2026

youtube-ops ("the tool") is a private, read-only command-line utility used exclusively by its owner to review analytics of YouTube channels owned and managed by the same owner. It has no third-party users. This policy describes what data the tool accesses and how it is handled.

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service and the Google Privacy Policy.

Data Accessed

With the owner's OAuth 2.0 consent (read-only scopes: youtube.readonly, yt-analytics.readonly), the tool accesses only:

  • The authenticated channel's ID and title
  • The owner's own videos and their public statistics (YouTube Data API v3)
  • Aggregated analytics reports for the owner's own channels, such as views, watch time, traffic sources, search terms, geography, devices, audience retention, and age/gender breakdowns (YouTube Analytics API). These reports are aggregated by YouTube and do not identify individual viewers.

Using an API key, the tool also reads publicly available data of other channels and videos (titles, view counts, durations, tags) for comparison purposes.

Data Stored

Stored only on the owner's personal computer:

  • OAuth tokens (access and refresh tokens), in local files readable only by the owner
  • JSON files containing the retrieved reports

No database, cloud storage, or remote server is used.

Purpose

Data is used for one purpose: helping the owner understand the performance of the owner's own channels and plan future content.

Data Sharing

None. The tool does not sell, share, transmit, or disclose any data to any third party. Data is exchanged only between the owner's computer and Google's APIs. No advertising or tracking services are used. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

  • OAuth tokens, client secrets, and API keys are kept in local files excluded from version control and are never published.
  • The tool requests only read-only scopes and communicates with Google APIs over HTTPS.

Data Retention and Deletion

Tokens and reports are retained locally until the owner deletes them. The owner can delete all stored data at any time by deleting the tool's local token and data folders. Since the tool has no third-party users, no other person's data exists to delete.

OAuth Revocation

Access can be revoked at any time at https://myaccount.google.com/permissions. After revocation, the stored tokens become invalid.
