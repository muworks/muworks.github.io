Personal Uploader CLI

A private, owner-only command-line utility for uploading original videos to the owner's own YouTube channels.

This page describes a private tool. The tool itself is not distributed and cannot be used by anyone other than its owner.

Purpose

Personal Uploader CLI is a private CLI (command-line) utility used exclusively by its owner to upload original videos to YouTube channels owned and managed by the same owner.

  • It is not a public service or SaaS product. There is no sign-up, no user interface for third parties, and no way for anyone other than the owner to use it.
  • Third-party users are not supported. The tool runs only on the owner's personal computer, using the owner's own OAuth credentials.
  • All uploaded videos are original content created or managed by the owner.

Who uses it

Only the owner. The tool has no third-party users, no customers, and no public access. It is used only for YouTube channels owned and managed by the same owner.

YouTube API usage

The tool uses the YouTube Data API v3 with OAuth 2.0:

  • videos.insert — uploads the owner's original videos. Every video is uploaded with privacyStatus=private. The tool never sets a video to public or unlisted, and never schedules publication.
  • channels.list (mine=true) — verifies, before every upload, that the authenticated channel matches the channel the owner intended (a safety check against uploading to the wrong channel).
  • videoCategories.list — resolves the numeric category ID for the category chosen by the owner.
  • videos.list — reads back the status of the owner's own uploads.

The final publishing decision is always made manually by the owner in YouTube Studio. The tool's role ends at "uploaded as private".

Data accessed and stored

  • The tool accesses only the owner's own channel information (channel ID and title) and the owner's own uploaded videos.
  • It does not access, collect, store, sell, or share any third-party YouTube data.
  • OAuth tokens are stored locally on the owner's personal computer and are never transmitted anywhere except to Google's APIs.
