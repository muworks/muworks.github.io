Privacy Policy — Personal Uploader CLI

Effective date: October 18, 2026

Personal Uploader CLI ("the tool") is a private command-line utility used exclusively by its owner to upload original videos to YouTube channels owned and managed by the same owner. It has no third-party users. This policy describes what data the tool accesses and how it is handled.

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service and the Google Privacy Policy.

Data Accessed

Through the YouTube Data API v3, with the owner's OAuth 2.0 consent (scopes: youtube.upload, youtube.readonly), the tool accesses only:

  • The authenticated channel's ID and title (channels.list, mine=true)
  • The owner's own uploaded videos and their processing/privacy status (videos.list)
  • Public video category metadata (videoCategories.list)

The tool does not access any other user's data, comments, subscriptions, analytics, or any third-party YouTube data.

Data Stored

Stored only on the owner's personal computer:

  • OAuth tokens (access and refresh tokens), in a local file readable only by the owner
  • Channel bindings: the owner's channel IDs and titles, used to prevent uploads to the wrong channel
  • Upload history: episode name, file hash (SHA-256), upload timestamp, and the returned YouTube video ID of the owner's own uploads
  • Local log files; access tokens and client secrets are masked and never written to logs

No database, cloud storage, or remote server is used.

Purpose

Data is used for exactly one purpose: uploading the owner's original videos to the owner's own channels as private videos, and verifying that each upload goes to the intended channel. The final publishing decision is made manually by the owner in YouTube Studio.

Data Sharing

None. The tool does not sell, share, transmit, or disclose any data to any third party. Data is exchanged only between the owner's computer and Google's APIs. No analytics, advertising, or tracking services are used.

Storage Location

All data is stored locally on the owner's personal computer in the tool's folder. Nothing is stored on remote servers operated by the owner or anyone else.

Security

  • OAuth tokens and client secrets are kept in local files excluded from any version control, and are never printed to the console or written to logs.
  • The tool requests the minimum OAuth scopes needed (youtube.upload, youtube.readonly) and communicates with Google APIs over HTTPS only.

Data Retention

  • OAuth tokens are retained until the owner deletes them or revokes access.
  • Upload history and logs are retained locally until the owner deletes them.

Data Deletion

The owner can delete all stored data at any time by deleting the tool's local token, history, and log files. Since the tool has no third-party users, no other person's data exists to delete. To request deletion of any data related to this tool, contact the owner at growing.cozy.chill@gmail.com.

OAuth Revocation

The owner can revoke the tool's access to Google/YouTube data at any time via the Google security settings page: https://myaccount.google.com/permissions. After revocation, the stored tokens become invalid, and the tool cannot access the YouTube API until re-authorized.

Contact
